# Ночной релиз

Веб-игра для дня знакомства со специальностью **Бизнес-информатика** в Финансовом университете.

Школьники играют со своих телефонов: спасают релиз приложения «ХлебТут» студии PIXEL OVEN. Злоумышленники из группы «КРАКЕН» ломают псевдокод — команды вроде `Показать(Логотип, 2 сек)` и `ЕСЛИ Заказ.Сумма >= 1000 ₽`. Между модулями кода есть задачи по экономике и праву.

Одна сессия — около 8–12 минут: 8 обязательных модулей и 3 необязательных сверхурочных.

## Экраны

| Адрес | Кто видит | Зачем |
| --- | --- | --- |
| `/` | школьник | регистрация, игра, результат |
| `/host` | проектор | QR-код и живая таблица лидеров |
| `/admin` | ведущий | закрыть запись, сброс, CSV |

## Запуск в день мероприятия

Нужны Node.js 20+ и общая Wi-Fi сеть с телефонами школьников.

```bash
cd University_game
npm install
cp .env.example .env
# в .env смените ADMIN_SECRET
npm run build
npm start
```

1. Узнайте IP ноутбука (`ip a` или `ipconfig`).
2. На проекторе откройте `http://ВАШ_IP:3000/host`.
3. В списке адресов выберите тот, который начинается с `192.168.` или `10.` — не `localhost`. Телефон не откроет localhost с ноутбука.
4. Если QR не открывается, проверьте: один Wi-Fi, не гостевая сеть с изоляцией клиентов, брандмауэр не блокирует порт 3000.

Для репетиции достаточно `npm run dev` и браузера на `http://localhost:3000`.

Если игру выкладываете в интернет, укажите публичный адрес в `PUBLIC_URL`, например `https://night-release.example.com`.

## Пароль ведущего

Страница `/admin`. Пароль берётся из `ADMIN_SECRET` в файле `.env`.

Не используйте пароль от компьютера и не показывайте его на проекторе.

## Как играть

1. Имя, школа, класс — для таблицы лидеров.
2. Восстановить модуль: расставить команды, вставить пропуски, найти лишнюю строку, ответить на вопрос или сопоставить фразу заказчика с функцией.
3. Неверный ответ снимает очки, подсказка тоже. Быстрый правильный ответ даёт бонус.
4. После двух ошибок можно сдаться без баллов и идти дальше.
5. После 8 модулей — сверхурочные или финиш.
6. На финише: очки, место и карточка навыков специальности.

## Сценарий ведущего (2–3 минуты)

1. «Мы студия PIXEL OVEN. Делаем приложения на заказ. Сегодняшний продукт — «ХлебТут» для сети пекарен «Корка». Ночью сборку сломала группа «КРАКЕН».»
2. Открыть `/host`, показать QR.
3. «В телефоне сначала будет брифинг: кто заказчик, что сломали, как чинить. Код ненастоящий — команды по-русски.»
4. Пока играют — комментировать таблицу и путь заказа: запуск → корзина → кнопка → деньги → скидка → закон → требования → курьеры.
5. В конце назвать топ-3 и коротко связать модули с предметами специальности.

## Если что-то пошло не так

- Телефоны не открывают ссылку: другой адрес в списке на `/host`, отключить изоляцию клиентов в Wi-Fi, `npm start` вместо только `dev`.
- Таблица пустая: кто-то должен нажать «Заступить на смену».
- Нужно начать поток заново: `/admin` → сбросить результаты.
- Между потоками: закрыть запись, наградить, сбросить, открыть запись.
